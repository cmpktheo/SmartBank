Customer :5102 + gRPC :6102 Postgres Redis RabbitMQ

Account directory — customers, bank accounts, holds. The only gRPC server.

Functionality

What it owns

  • REST (Endpoints/AccountEndpoints.cs): GET /api/accounts, GET /api/accounts/{id}, POST /api/accounts (OpenAccountCommand), GET /api/accounts/iban/{iban}, GET /api/customers/me.
  • gRPC AccountDirectory (6 RPCs: GetAccountStatus, LookupByIban, Reserve/Release/Commit/CreditFunds) over CustomerDbContext; reserve idempotent on hold_id.
  • Async: consumes customer.ledger.transferred (CaptureHold + CreditPosted); HoldExpiryWorker compensates Reserve-without-Book. Bank defaults GB / NWBK / 601613.
