Ledger :5103 Postgres Redis RabbitMQ gRPC client

Money movement + double-entry journal. The most connected service.

Functionality

What it owns

  • POST /api/transfers requires Idempotency-Key: guid → TransferFundsCommand(sourceAccountId, destinationIban, amount, currency, …) → 201 {transactionId, reference, bookedAt}; Customer down → 503 CUSTOMER_UNAVAILABLE.
  • Statements: GET /api/ledger/accounts/{id}/transactions (from/to/type/kind/page), …/recent, …/statement.csv with running balance.
  • gRPC client AccountDirectoryClientAdapter (3s deadlines); RedisIdempotencyStore; OutboxDispatcher polls outbox_messages → smartbank.ledger.
