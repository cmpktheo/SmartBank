API Gateway :5100 stateless YARP 2.2.0

Single public front door. JWT check, Redis logout-blacklist, CORS, security headers, YARP routing.

Functionality

What it does

  • Reverse proxy (AddReverseProxy().LoadFromConfig + MapReverseProxy()) — routes in appsettings.Development.json → ReverseProxy.
  • Validates JWT HS256 (authority http://localhost:5101, dev key dev-signing-key-32-bytes-long!!!!!!).
  • JwtBlacklistMiddleware: rejects logged-out JTIs via Redis.
  • CORS allow http://localhost:4200; security headers; /health/live|ready (ready checks Redis).
