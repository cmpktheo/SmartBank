Identity :5101 Postgres Redis no RabbitMQ

Auth authority — users, passwords, MFA, OpenIddict tokens.

Functionality

What it owns

  • ASP.NET Identity + IdentityDbContext; OpenIddict server at /connect/token (password + refresh flow, scopes smartbank.api, offline_access, 15m / 14d).
  • Endpoints (Endpoints/AuthEndpoints.cs): POST /api/auth/login → LoginCommand (+MFA challenge), POST /mfa/verify|resend|refresh|logout, GET /me, GET /connect/jwks.
  • Logout writes JTI to Redis blacklist; dev seeds alex.morgan@ / jordan.lee@ (123456) via IdentitySeed.
  • E2E seam GET /api/auth/e2e/otp only when E2E_OTP_SEAM=true.
