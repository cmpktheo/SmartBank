What this system is, how it fits together, where to go next.

Start here

SmartBank is a microservices demo bank

Six ASP.NET Core entry points (YARP gateway + 5 domain services), an Angular 20 SPA, five Postgres databases, Redis, RabbitMQ, and a full OpenTelemetry + Prometheus + Loki + Tempo + Grafana stack — all runnable locally with docker compose up + scripts/start-apis.ps1.

6 services

Gateway :5100, Identity :5101, Customer :5102 (+gRPC :6102), Ledger :5103, Cards :5104, Notification :5105.

DB per service

5× postgres:16.6-alpine on ports 5433–5437. No shared database.

2 comm styles

Synchronous REST via gateway + gRPC Ledger→Customer, and async RabbitMQ events.
