Run it locally

Windows 10/11 + WSL2 + Docker Desktop (Linux containers). All commands from repo root unless noted.

Boot order

Infra → migrate → APIs → SPA

Copy-Item ".env.example" ".env"   # first time only
docker compose up -d
docker compose ps
./scripts/migrate-seed.ps1        # builds slnx, boots APIs, waits /health/ready
                                # to re-seed the DBs first run: docker compose down -v
./scripts/start-apis.ps1          # identity 5101, customer 5102+6102, ledger 5103, cards 5104, notif 5105, gateway 5100
cd frontend/smartbank-web         # new shell for the SPA
npm ci                            # first time only
npm start                         # serves :4200

Seed logins (123456): alex.morgan@smartbank.test, jordan.lee@smartbank.test. start-apis.ps1 sets E2E_OTP_SEAM=true so GET /api/auth/e2e/otp?email=… works. Logs .logs/, PIDs .pids/, stop with ./scripts/stop-apis.ps1.

Verify & test

Health, tests, E2E

dotnet test SmartBank.slnx            # backend (stack must be up)
cd frontend/smartbank-web; npm test   # vitest
npx playwright install chromium; npm run e2e   # serves :4200, talks to :5100

Grafana http://localhost:3000 (admin / smartbank_dev_only), RabbitMQ UI :15672. docker compose down keeps data; -v wipes it.
