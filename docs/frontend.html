Stack & wiring

What to know

  • Angular 20 + TS 5.8 + RxJS 7.8 + Tailwind 4.3 + lucide icons; apiBaseUrl=http://localhost:5100 (src/environments/environment.ts).
  • Auth interceptor attaches JWT + X-Correlation-Id; prefix sb; styles tailwind.css + styles.scss (ink #05080f, primary #2563eb).
  • Commands: npm ci → npm start (:4200) → npm test (vitest) → npm run e2e (playwright, needs gateway + E2E_OTP_SEAM=true).
