Suggested test flow

  1. Log in as alex.morgan@smartbank.test / 123456 (complete the MFA step).
  2. Copy Jordan's Main IBAN above, open Transfers, pick Alex's Everyday as source and paste the IBAN as destination.
  3. Submit, then check both users' statements — and GET /api/notifications/log for the async notification.
These IBANs are stable — CustomerSeed always re-creates the three accounts with fixed numbers 1000000004 / 1000000005 / 1000000006 (via IbanFactory with sort code 601613), then fast-forwards account_number_seq past them without rewinding it, so accounts you open in the app (Repositories.cs:31) never collide. If you wiped the DB volumes (docker compose down -v) the same three IBANs come back. If verification ever fails, re-check the live IBANs in the app's Accounts page or query them directly:
docker exec smartbank-postgres-customer-1 psql -U smartbank -d smartbank_customer -c "SELECT alias, iban FROM bank_accounts;"
